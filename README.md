# Orion Launcher

High Performance Native Game Engine & Modpack Launcher written in Rust.

## Características
- **Motor Nativo Rust & wgpu:** Latencia ultrabaja de 104 ms y renderizado de alto rendimiento.
- **Skins y Capas No-Premium:** Sincronización instantánea en la nube (Orion Cloud Vault).
- **Multijugador Nexus LAN:** Túnel P2P de baja latencia con códigos de invitación directos.
- **Liquid Glass UI:** Interfaz moderna con temas dinámicos reactivos.
- **Auto-Actualizador Descentralizado:** Actualizaciones automáticas con reemplazo en caliente en Windows.
